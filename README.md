# AV-Scanner-Updater 1.0

**Автоматический загрузчик антивирусных сканеров в указанную папку**

[Скачать релиз](https://github.com/artemsoft2025/AV-Scanner-Updater/releases/download/1.0/AVScannerUpdater.zip)

---

## ОПИСАНИЕ

Умный загрузчик антивирусных сканеров, который автоматически проверяет и загружает актуальные версии популярных антивирусных утилит. Программа скачивает файлы только при необходимости (изменился размер или версия).

---

## ПОДДЕРЖИВАЕМЫЕ СКАНЕРЫ

- Malwarebytes - с автоматическим поиском новых версий
- Dr.Web CureIt - лечащая утилита
- Kaspersky Virus Removal Tool (KVRT) - сканер для удаления вирусов
- Emsisoft Emergency Kit - аварийный комплект
- ESET Online Scanner - онлайн сканер
- AdwCleaner - для удаления рекламного ПО
- Пользовательские сканеры - через конфигурационный файл

---

## АРГУМЕНТЫ КОМАНДНОЙ СТРОКИ

Основные параметры:
```cmd 
--help, -h              Показать эту справку
--no-wait, -n           Не ждать нажатия Enter в конце (для автоматических заданий)
--config, -c FILE       Указать свой конфигурационный файл
```

---

##  ПРИМЕРЫ ИСПОЛЬЗОВАНИЯ
1. Обычный запуск (с ожиданием Enter): 

`AVSUp.exe`

2. Для автоматических заданий (без ожидания):
 
`AVSUp.exe --no-wait`

3. С указанием своего конфигурационного файла:
 
`AVSUp.exe --config my_config.ini`

4. Короткая форма параметров:
 
`AVSUp.exe -n -c my_config.ini`

5. Для Планировщика заданий Windows:
 
`AVSUp.exe --no-wait`


## КОНФИГУРАЦИЯ

Файл настроек `av_config.ini`:
```cmd
[Settings]
DownloadFolder = ./av_scanners     ; Папка для загрузки файлов
MaxWorkers = 3                     ; Количество одновременных загрузок
EnableSmartMalwarebytes = True     ; Включить умный поиск версий Malwarebytes

[Scanners]
; Включить или выключить конкретные сканеры (True/False)
Malwarebytes = True
DrWebCureIt = True
KasperskyKVRT = True
EmsisoftEmergencyKit = True
ESETOnlineScanner = True
AdwCleaner = True

[CustomUrls]
; Добавьте свои сканеры (одна ссылка на строку)
; Формат: Имя = URL
MyScanner1 = https://example.com/scanner1.exe
MyScanner2 = https://example.com/scanner2.exe
```

## НАСТРОЙКА ДЛЯ АВТОМАТИЧЕСКОГО ЗАПУСКА

Планировщик заданий Windows:

1.	Откройте «Планировщик заданий»
2.	Создайте новое задание
3.	В действии укажите:  C:\путь\к\AVSUp.exe --no-wait
4.	Настройте расписание (например, ежедневно в 10:00)

## ОСОБЕННОСТИ

- Умное обновление - файлы скачиваются только при изменении размера или версии
- Автопоиск версий - для Malwarebytes автоматически ищет актуальные версии
- Подробный прогресс - отображение скорости загрузки и оставшегося времени
- История загрузок - ведется журнал скачанных файлов
- JSON отчеты - сохраняется информация о каждой загрузке

## ВЫХОДНЫЕ ДАННЫЕ

Программа создает:
- av_scanners/ - папка с скачанными файлами
- download_history.json - история загрузок
- download_report.json - отчет о последней загрузке
- av_config.ini - файл настроек (создается автоматически при отсутствии)

## ПОЛУЧЕНИЕ ПОМОЩИ

Для получения справки используйте:

`AVSUp.exe --help`

Программа автоматически создаст все необходимые файлы при первом запуске!
